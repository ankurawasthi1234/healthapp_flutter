# HealthApp

A modern Flutter health dashboard designed to help users quickly view upcoming appointments, access common health services, and explore nearby doctors.

## App Preview

![HealthApp dashboard preview on Mi A3](mi_a3_healthapp.png)

## Current UI Overview

The interface includes:

- A personalized greeting with a notification and search action bar
- An upcoming appointment card for Dr. Winnie Ballard
- A Health Needs section with options such as Appointment, Hospital, Covid-19, and More
- A Nearby Doctors list with doctor profiles, specialty details, and review ratings

## Run the app

```bash
flutter pub get
flutter run
```

## Technologies

- Flutter
- Dart
- Material Design UI
